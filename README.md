# Cybersecurity Lab Notes

Welcome to my personal cybersecurity lab repository!

This repository documents my hands-on cybersecurity experiments, practical learning experiences, technical commands and troubleshooting processes.

The purpose is to build a personal technical knowledge base that I can revisit whenever I need to review a tool, reproduce an experiment or troubleshoot a similar issue.

## Documentation Approach

Each lab includes:

- **Overview** — Purpose of the experiment.
- **Environment** — Operating system, tools and setup.
- **Step-by-Step Guide** — Commands and practical procedures.
- **Command Explanation** — What each command does and why it is used.
- **Troubleshooting** — Errors encountered and solutions.
- **Results & Lessons Learned** — Findings and key technical concepts.

## Disclaimer

All experiments are conducted in personally owned or authorised environments for educational purposes. Sensitive data, credentials and private forensic evidence are excluded from this repository.
